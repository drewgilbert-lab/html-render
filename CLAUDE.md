# Instructions for Claude Code

Before taking any GitHub-related action in this repo — creating or naming a
branch, committing, opening or writing a pull request, merging, tagging a
release, or touching `.github/workflows/` — read
[docs/github-process.md](docs/github-process.md) and follow it. It defines
when this repo requires a branch + PR versus a direct commit to `main`,
branch naming, commit message prefixes, PR content requirements, merge
strategy, and the tag/release sequence.
